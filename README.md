# System Monitoring Tool

Multi-platform system monitoring tool for Windows and Linux with real-time metrics and alerts.

## Features
- Real-time monitoring: CPU, Memory, Disk, Network, Processes
- Cross-platform: Windows & Linux support
- Multiple interfaces: CLI and Web dashboard
- Configurable alerts via email, Slack, or webhooks
- Export metrics to CSV/JSON
- Lightweight and easy to deploy

## Quick Start
```bash
git clone https://github.com/Falconmx1/system-monitoring.git
cd system-monitoring
pip install -r requirements.txt
python src/main.py
